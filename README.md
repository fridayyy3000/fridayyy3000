### MCPGuard — Secure Agent Control Plane
![TypeScript](https://img.shields.io/badge/-TypeScript-3178C6)
![MCP](https://img.shields.io/badge/-MCP-7F7FDD)
![React](https://img.shields.io/badge/-React-61DAFB)

Four-component control plane for MCP-powered AI agents: MCP server with Zod validation, HTTP security gateway with Bearer auth and RBAC, streaming LLM guardrail with incremental PII redaction across partial SSE chunks, and token-aware model router with SQLite rate limiting and provider fallback. ### QUIETT — Agentic ETL for Table Canonicalization

### SentryLine — Clinical RAG QA System
